# Twin Peaks Village website

Static site, no framework. Everything is generated by two Python scripts.

- `src/build.py` holds all page content and writes the HTML into `dist/`. Placeholders are written as `tbd("...")` so they are easy to search for and remove.
- `src/data.py` lists every gallery photo with its caption, category and whether it is virtually staged (S) or a twilight sky edit (T).
- `src/assemble.py` copies images, video, logos and public PDFs from the project folder into `dist/`, then runs the build. Run it after changing photos or documents: `python3 website/src/assemble.py`
- `dist/` is the folder Netlify publishes. `dist/netlify.toml` sets no-index headers while this is a preview.

Only files under `dist/docs/` are public downloads. The listing agreement, MLS sheets and strategy document are never copied into the site.

Before going public: remove the preview ribbon and the noindex lines (build.py and netlify.toml), replace every placeholder, and have counsel approve legal.html and the footer.
